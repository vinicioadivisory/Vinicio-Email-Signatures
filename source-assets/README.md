# Source Assets

This folder contains the original source materials used to create, maintain, and update Vinicio Adivisory email signatures.

Unlike the `/images` folder, the files stored here are not necessarily loaded directly by the live HTML email signatures.

The purpose of this folder is to preserve the original branding and employee assets so future signature updates can be completed without having to recover or recreate the source files.

## What Belongs in This Folder

Examples of files that should be stored here include:

* Original Vinicio Adivisory company logos
* Trademark logo versions
* Arabic logo versions
* Original employee photographs
* Original QR-code images
* Branding graphics used to create signature designs
* Other approved source materials required for future signature updates

## Current CEO Source Assets

The source materials for the CEO email signatures may include:

* Vinu Pillai's original photograph

* Vinicio Adivisory Arabic logo
* Vinicio Adivisory trademark logo
* Other approved company branding assets

## Difference Between `/source-assets` and `/images`

### `/source-assets`

Contains the original files used to create or modify email signatures.

These files are retained primarily for editing, maintenance, backup, and future signature development.

### `/images`

Contains the production files that are referenced directly by the live HTML email signatures.

Examples include:

* Final signature image slices
* LinkedIn icons
* Instagram icons
* Facebook icons
* Calendar or meeting icons

The `/images` folder should remain focused on files required by the deployed signatures.

## File Naming

Use clear and descriptive filenames whenever new source materials are added.

Recommended examples:

* `vinu-pillai-photo.jpg`
* `vinu-pillai-contact-qr.png`
* `vinicio-logo-arabic.png`
* `vinicio-logo-trademark.png`

Avoid vague filenames such as:

* `image1.png`
* `logo-new.png`
* `final-final.png`
* `photo2.jpg`

Clear filenames make future maintenance significantly easier.

## Updating Source Assets

When replacing an employee photograph, logo, QR code, or other source asset:

1. Confirm that the new file is officially approved.
2. Use a clear and descriptive filename.
3. Upload the new source file to this folder.
4. Do not immediately delete the previous production signature.
5. Create and test the updated signature first.
6. Replace the live production version only after testing is complete.

## Important

Files stored in this folder may be used to create future production signatures, but they should not automatically be assumed to be live or currently deployed.

Always check the corresponding HTML and `/images` production files to determine which assets are currently being used.

## Security

This repository is publicly accessible because the email signature assets need to load for external email recipients.

Only public-facing and approved company materials should therefore be stored in this folder.

Do not upload:

* Passwords
* API keys
* Private credentials
* Internal company documents
* Confidential employee information
* Sensitive personal information
* Private business records

Only assets approved for public company use should be stored here.
